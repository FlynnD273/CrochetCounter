# ⚠️ This repository has migrated to [Codeberg](https://codeberg.org/FlynnD273/crochet-counter)

Counts stitches in a row. Supports standard notation like (dec, sc 7) x 6 and will let you advance each stitch using the buttons. The way I use it is by placing my keyboard on the ground and pressing the spacebar with my foot to advance the stitch
